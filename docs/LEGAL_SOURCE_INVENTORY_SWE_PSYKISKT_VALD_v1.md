- lagrådsremiss `En särskild straffbestämmelse för psykiskt våld`
- future official Åklagarmyndigheten guidance, if a dedicated source appears
- future official police/prosecution guidance, if a dedicated source appears
- later official case-law source bucket only as candidate bucket, not doctrine application now

Source candidates are not doctrine application, not legal advice, not offence determination, and not case application.

## Source-Priority Model

Official-source-first Swedish source hierarchy:

1. Current official consolidated statute text first.
2. Enacted amending SFS text and consolidated official text next.
3. Proposition, betänkande, and riksdagsskrivelse next.
4. Ds, remissmaterial, and lagrådsremiss materials next.
5. Future official guidance only as non-controlling official context unless otherwise legally reviewed.
6. Case-law only as later verified source-candidate bucket, not doctrine application now.

The source-priority model does not rank case facts, does not weigh evidence, and does not select any legal outcome.
