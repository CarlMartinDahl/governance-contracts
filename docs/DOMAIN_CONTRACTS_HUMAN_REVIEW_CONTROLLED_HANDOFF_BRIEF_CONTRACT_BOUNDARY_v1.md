## 1. Purpose

This docs-only boundary freezes the Owner-selected version 1 contract semantics
for the `CONTROLLED_HANDOFF_BRIEF` output family in the Human Review Workspace.
The candidate is one closed, packet-scoped, reference-only object. It names
exactly one separately governed candidate from each of the six preceding Human
Review output families through six pairwise-unique opaque references.

The brief remains `HANDOFF_CANDIDATE_ONLY`. It is not a completed handoff,
approval, sign-off, release, export, delivery, recipient authorization, or
external-use decision. Human correction and approval remain separate future
contracts and workflows.

This document creates no JSON Schema, validator-result schema, validator,
package export, cross-reference checkpoint, assembly function, approval
workflow, persistence surface, API, route, user interface, export, delivery,
provider/model execution, product candidate, or external-use authorization. It
processes no raw, private, source, case, identity, authorship, or real-evidence
material.

Human/professional review remains the release gate.
