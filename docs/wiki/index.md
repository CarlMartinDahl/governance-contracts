# Project Wiki

This wiki is a tracked repo orientation and coordination layer.

It is not the primary source of truth for implementation, tests, PR status, CI
status, legal or compliance status, or model readiness. Live git state, tracked
repo files, GitHub PR metadata, and verified CI metadata win over wiki text.

Chat, pasted summaries, private notes, uploaded conversation material, and
non-repo files are advisory only. They must not be copied into this repo wiki
unless a separate tracked-doc decision authorizes that work.

## Read First

Every new thread should ask Codex to read these files first:

- `docs/wiki/index.md`
- `docs/wiki/log.md`

Future wiki updates must re-read both files before editing them.

## Update Rules

Future wiki updates must be docs-only slices. Before editing, verify:

- repo root
- branch
- live remote `main`
- local `governance/main`
- tracked diff
- staged diff
- known unrelated untracked paths

Wiki updates must not create implementation, runtime behavior, source edits,
package edits, tests, security findings, severity assignments, remediation,
release approval, external-use authorization, product-candidate selection,
technical sign-off, runtime certification, court-ready claims, AI Act compliance
claims, high-risk approval claims, or legal, clinical, evidentiary, or
case-truth conclusions.

## Entry Discipline

Wiki entries should distinguish:

- verified tracked repo evidence
- advisory context
- open questions
- non-authorizations

Missing or stale wiki content must not be treated as completion, approval, or
blocker closure.
