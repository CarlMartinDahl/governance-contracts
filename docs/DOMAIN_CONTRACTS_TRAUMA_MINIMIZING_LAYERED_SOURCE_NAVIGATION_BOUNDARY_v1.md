# Trauma-Minimizing Layered Source Navigation Boundary

Contract name: `TRAUMA_MINIMIZING_LAYERED_SOURCE_NAVIGATION_BOUNDARY`.

Status: `DOCS_ONLY`.

Purpose: freeze a narrow product-doc boundary for trauma-minimizing layered source navigation using text-primary first, marker/pointer/review-route language, no raw-detail replay, and human/professional review as the release gate.

## Core Rule

`TRAUMA_MINIMIZING_LAYERED_SOURCE_NAVIGATION`.

The model must begin with the smallest available text-primary layer when available.

The text-primary layer is used first to identify neutral markers, review candidates, privacy blockers, counter-context needs, and review routes.

The text-primary layer must not be used to create conclusions.

The model must use marker, pointer, and review-route language rather than raw-detail replay.

The purpose is minimum necessary exposure and reduced user re-reading of distressing material.

## Layer Sequence

Allowed layered workflow structure:

`original protected source layer`
-> `clean/image-free PDF layer`
-> `text-primary export layer`
-> `neutral marker inventory`
-> `controlled pointer to PDF`
-> `controlled pointer to original media/metadata only if needed`
-> `human/professional review`

A large original source package may contain SMS/message history, images, and metadata.

A smaller image-free or cleaned PDF layer may be derived from the original source.

A smallest text-primary export may be derived from the PDF/source material.

Text-primary review must come first when that layer is available.

Markers may open controlled pointer/search routes to the PDF layer.

PDF-layer review may open controlled pointer/search routes to the protected original media/metadata layer only when necessary for human/professional review.

## No-Raw Default

Raw messages, screenshots, images, metadata, source locators, filenames, private paths, page references, URLs/tokens, sensitive dates, medical details, intimate details, child details, and third-party details must not be displayed by default.

The model must not replay raw messages.

The model must not display images or screenshots by default.

The model must not expose metadata, source locators, filenames, private paths, page references, URLs/tokens, or sensitive private details as user-facing output by default.

## Allowed Output Style

Allowed output style:

- marker present
- review route opened
- pointer unresolved
- source layer not searched by scope
- privacy blocker
- counter-context required
- ordinary-context required
- human/professional review required
- validation without conclusion

## Source-Universe Declarations

Layered source navigation must preserve source-universe declarations.

Allowed source-universe statuses:

- searched
- not searched
- not searched by scope
- unavailable
- requires human/professional review

Source-universe declarations must not be converted into conclusions.

The model must preserve counter-context and ordinary-context requirements.

If counter-context or ordinary context is missing, the model must mark it as required, not infer it.

## Pointer And Layer Conflict Rules

If a pointer cannot be resolved across layers, the model must stop or mark the pointer unresolved.

The model must not infer unresolved pointer content.

If layer mapping conflicts, the model must fail closed and require review.

If text-primary evidence is insufficient, the model must not say that nothing happened.

If text-primary evidence is insufficient, the model must not say that the user was not exposed.

The model may only say that this layer does not support further navigation without more context, resolved pointers, or human/professional review.

## Metadata And Marker Non-Proof Rule

The model must not turn text markers, image metadata, timestamps, repetition, silence, read receipts, filenames, page positions, or source-layer proximity into proof.

Metadata may be treated only as process, source-navigation, privacy, or review-routing context.

Markers may support controlled review routes, not conclusions.

## Forbidden Output Style

Blocked output style:

- raw replay of messages
- image/screenshot display by default
- metadata as proof
- source locator as user-facing output
- legal conclusion
- clinical conclusion
- evidentiary conclusion
- credibility finding
- victim-status finding
- perpetrator-status finding
- offence finding
- ownership finding
- risk score
- sufficiency score
- police-report text
- pleading text
- external-use readiness
- product-candidate selection

The model must not create legal, clinical, evidentiary, credibility, victim-status, perpetrator-status, offence, ownership, risk, sufficiency, police-report, pleading, external-use, or product-candidate conclusions.

## Human Review Boundary

Human/professional review remains the release gate.

Layered source navigation may reduce exposure, organize uncertainty, and route review work.

Layered source navigation does not replace human/professional review.

Layered source navigation does not authorize external use.

Layered source navigation does not authorize product-candidate selection.
