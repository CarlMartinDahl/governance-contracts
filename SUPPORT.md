# Support

This project is provided as an open-source governance and contract foundation.
It is not legal advice, professional review, a hosted service, or authorization
to process real private material.

Use a public GitHub issue for reproducible bugs and bounded feature proposals.
Before opening an issue:

1. Search existing issues.
2. Reproduce the problem against the current `main` branch.
3. Remove credentials, personal data, private case material, source locators,
   and confidential context.
4. Include the smallest synthetic example and the relevant test output.

Use the private route in [SECURITY.md](SECURITY.md) for suspected
vulnerabilities or sensitive security details. Security reports and support
requests do not create release approval, legal conclusions, or professional
review.
