# Security Policy

## Supported versions

This repository is an early contract and reference implementation. Only the
current `main` branch receives security updates.

## Private reporting

Do not report suspected vulnerabilities, credentials, personal data, private
case material, or exploit details in a public issue.

Use GitHub Private Vulnerability Reporting:

https://github.com/CarlMartinDahl/governance-contracts/security/advisories/new

Include the affected component, impact, reproduction steps, and any suggested
mitigation. Avoid attaching real private or evidentiary material. A maintainer
will acknowledge the report through the private advisory and coordinate any
disclosure.

## Scope

The repository is not a deployed service and does not claim a production
security posture. Reports about concrete weaknesses in its code, schemas,
validators, handlers, persistence adapter, workflows, or documented security
boundaries are welcome. General legal conclusions and reports that require
sharing real private source material are outside this channel.
